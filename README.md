# 📊 Investment Prediction Using Machine Learning

A machine learning project for predicting investment-related outcomes using customer and campaign information. The project applies multiple classification algorithms and evaluates their performance to identify an effective predictive model.

## 📌 Project Overview

This project focuses on using machine learning techniques to analyze customer and marketing campaign data and build predictive models for investment-related outcomes.

The dataset contains customer demographic information, financial-related attributes, contact details, and campaign-related information. Different machine learning classification algorithms are implemented and evaluated to compare their predictive performance.

## 🎯 Objectives

- Perform data preprocessing and exploratory analysis.
- Analyze customer and campaign-related features.
- Prepare the dataset for machine learning.
- Implement multiple classification algorithms.
- Train and test the models using the available dataset.
- Evaluate and compare model performance.
- Identify a suitable model for investment prediction.

## 🧠 Machine Learning Algorithms

The project implements the following classification algorithms:

- Logistic Regression
- K-Nearest Neighbors (KNN)
- Naive Bayes
- Decision Tree
- Random Forest
- Support Vector Machine (SVM)

## 📂 Dataset

The project uses `Investment.csv`.

The dataset contains customer and campaign-related information, including attributes such as:

- Job
- Marital Status
- Education
- Default
- Housing
- Loan
- Contact
- Month
- Day of Week
- Campaign
- Previous Contacts
- Pdays
- Poutcome
- Other campaign-related attributes

The dataset is included in this repository so that the notebook can be reproduced using the same data.

## ▶️ How to Run the Project

### 1. Clone the repository

```bash
git clone https://github.com/Srushti316/Investment-Prediction.git
```

### 2. Open the project

Open the project folder in Jupyter Notebook or JupyterLab.

### 3. Open the notebook

Open:

```text
InvestmentPrediction_Project02.ipynb
```

### 4. Make sure the dataset is available

Keep:

```text
Investment.csv
```

in the same project folder as the notebook.

### 5. Run the notebook

Run the notebook cells sequentially to perform the data analysis, preprocessing, model training, prediction, and evaluation.
