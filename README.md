# Investment Prediction using Machine Learning

## Project Overview
This project focuses on predicting investment outcomes using machine learning techniques. The project uses a dataset containing customer and campaign-related information to build a predictive model.

## Technologies Used
- Python
- Pandas
- NumPy
- Matplotlib
- Seaborn
- Scikit-learn
- Jupyter Notebook

## Machine Learning
The project uses Logistic Regression for prediction and `train_test_split` for dividing the data into training and testing sets.

## Project Files
- `InvestmentPrediction_Project02.ipynb` — Jupyter Notebook containing the complete project code, data analysis, visualization, model building, and prediction.

## How to Run
1. Download or clone this repository.
2. Open `InvestmentPrediction_Project02.ipynb` using Jupyter Notebook or JupyterLab.
3. Run the notebook cells sequentially.
